# Build inspector futuro

Questa cartella è riservata alla futura reintroduzione dell'import e della visualizzazione completa di build Path of Building.

La prima versione dell'archivio usa soltanto link esterni. Non analizza codici PoB, XML, oggetti, gemme, passive tree o statistiche.

Quando verrà ripresa questa funzione, qui potranno vivere:

- parser PoB;
- tipi dati importati;
- visualizzatore della scheda build;
- equipaggiamento e slot;
- gemme;
- passive tree;
- statistiche;
- compatibilità PoE 1 e PoE 2.

I file attuali non sono cancellati automaticamente per evitare di perdere modifiche locali non ancora revisionate.
